# Baseline Survival Calculator v0

## What this does
Simulates whether a fixed financial position survives under conservative stress assumptions.

## Assumptions
- All values are deterministic and visible in the script
- Rent is stressed downward
- Costs are stressed upward
- No growth, no optimisation, no behavioural change

## What this does NOT do
- Does not recommend actions
- Does not optimise returns
- Does not model uncertainty
- Does not use AI
- Does not predict the future
